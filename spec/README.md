# The Truss spec

Start with [SPEC.md](SPEC.md). [CHANGELOG.md](CHANGELOG.md) lists what changed in each version, and [EXTENSIONS.md](EXTENSIONS.md) lists custom fields and types several teams use.

- [schemas/](schemas/): JSON Schema for each type, `types.json` and `links.json`.
- [example/](example/): a small repo that passes every required check.
- [conformance/](conformance/): repos a checker must accept or reject.
